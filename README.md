# Employee Database SQL Assignment

## Project Overview
This project focuses on practicing SQL queries using an Employee Database. It includes employee details, department information, and location data.

## Topics Covered
- SELECT and DISTINCT
- WHERE conditions
- UPDATE statements
- Column aliases
- ORDER BY and LIMIT
- Aggregate Functions (MIN, MAX, AVG, SUM, COUNT)
- GROUP BY and HAVING
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN

## Database Tables
- Employees
- Departments
- Location

## Tools Used
- SQL
- MySQL

## Project Objective
The objective of this project is to improve SQL skills by writing queries, filtering employee records, calculating salary statistics, and joining multiple tables.

## Conclusion
This assignment helped me practice SQL fundamentals and understand how to retrieve, analyze, and manage data using SQL.
